# Mogoの主页

基于原生 HTML、CSS 和 JavaScript 的静态个人主页。无需构建步骤或服务器端运行时，发布目录就是仓库根目录。

## 部署

- **Cloudflare Pages / Netlify / Vercel**：将仓库连接到项目，构建命令留空，发布目录设为仓库根目录。
- **GitHub Pages**：把仓库根目录发布为 Pages 内容，并在 Pages 设置中绑定 `moxan.top`；仓库根目录已经包含 `404.html`。
- **Nginx**：将站点根目录指向仓库目录。项目已提供 `index.html` 与 `404.html`。

网站的默认图片、字体与网易云音乐数据使用外部服务。网易云 API 地址与请求路径集中配置在 `app.js` 顶部的 `MUSIC_API` 中；如果接口或浏览器跨域策略阻止请求，播放器会切换到离线提示并保留歌单外链。

音乐会在入站时尝试自动随机播放；播放器可切换随机播放、单曲循环和列表顺序，选择的模式保存在当前浏览器。浏览器若拦截有声自动播放，会提示访客点击播放器继续。

左侧悬浮迷你播放器显示封面、歌曲信息与当前歌词。拖住控件顶部的把手可上下移动，桌面端和手机端分别记住位置。

访客留言、桌面外观设置保存在当前浏览器的 `localStorage`。每次进入主页都会从 `images.js` 的壁纸列表中随机挑选，并尽量避免与上一次重复；亮度等其他外观设置会保留。自定义上传壁纸由浏览器本地预览，不会上传到服务器；刷新页面后需要重新选择文件。

## 替换图片

所有可替换图片统一在项目根目录的 `images.js` 中配置，包含头像、桌面壁纸、关于页横幅、身份卡片、游戏卡片，以及可选的音乐封面兜底图。图片可以使用网络 URL，也可以放到 `assets/images/` 并填入相对路径（例如 `./assets/images/avatar.webp`）。详细说明见 [`assets/images/README.md`](assets/images/README.md)。

主页右下角的 Live2D 猫咪配置位于 `live2d.js`，模型由 CDN 加载；若一个脚本 CDN 不可用，会自动尝试备用 CDN。
